# Project guidance

This repository contains a Next.js service-management application. Use the README for setup and `package.json` for available checks.

- Keep changes scoped to the requested work and preserve unrelated changes.
- Store credentials in ignored environment files or the deployment provider's secret store. Commit only placeholder values in `.env.example`.
- Keep personal workspace notes, customer records, signed consent evidence, account recovery material and admin captures outside the repository.
- Use synthetic records for examples and tests. Never copy production customer data into fixtures or documentation.
- Use repository-relative paths and generic deployment examples in documentation.
- Do not deploy, alter production data, rewrite history or change repository visibility without authorization for that action.
- Check the diff and run checks appropriate to the changed files before committing.
